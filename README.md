# KDPsych Study Platform — Question Bank

Interactive psychiatric exam preparation platform with 5,823 questions, clinical explanations, full progress tracking, and mobile PWA optimization.

## Features
- **58 Chapters & Subjects**: Comprehensive psychiatric syllabus.
- **Interactive Quiz Engine**: Instant feedback, explanations, and diagrams.
- **Mobile Optimized**: Swipe navigation, native tactile haptic feedback, thumb ergonomics.
- **Progress Persistence**: Auto-saves locally and syncs across devices.
- **Custom Bank Importer**: Import future `.json` banks seamlessly.
